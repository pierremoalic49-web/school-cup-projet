# Assets — ce que le porteur du projet doit déposer ici

Plus ces dossiers sont remplis, plus le site sera réaliste. Claude Code doit vérifier ce qu'il y a dedans avant de commencer
et signaler ce qui manque.

| Dossier | Quoi mettre | Où trouver | Statut |
|---|---|---|---|
| `stade-3d/` | Un modèle 3D de stade de foot (format `.glb` ou `.gltf` de préférence) | Sketchfab (filtre « Downloadable » + licence CC-BY ou CC0), CGTrader, Poly Haven pour les textures | À fournir |
| `photos/joueurs/` | Photos des joueurs : de face, cadrées à la taille, sur fond uni, avec le maillot. Nom du fichier = prénom-initiale-classe.jpg | Prises au lycée | **Uniquement avec l'autorisation des parents** |
| `photos/ambiance/` | Photos du terrain, du lycée, d'anciens matchs, des supporters | Prises au lycée | Optionnel |
| `sons/` | Ambiance de foule (boucle), clameur de but, coup de sifflet | Freesound.org (licence CC0 de préférence), Pixabay sons | Optionnel : sinon sons générés par le code |
| `logo/` | Le logo School Cup s'il est dessiné (SVG ou PNG transparent) | Créé par l'équipe | Optionnel : sinon logo typographique |

Toujours noter la source et la licence de chaque fichier téléchargé dans `assets/CREDITS.md`.
