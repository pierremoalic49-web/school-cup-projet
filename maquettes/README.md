# Maquettes

## school-cup-3d.html — maquette validée (référence principale)

Double-clic pour l'ouvrir dans Chrome ou Edge. **Il faut être connecté à internet** (la 3D et les polices se chargent en ligne).

Ce qu'elle montre :
- l'intro : stade 3D de nuit vu du ciel + logo School Cup ;
- la cinématique au clic sur « Entrer dans le stade » (avec le son, monte le volume) ;
- le site par-dessus le stade : direct, tableau garçons / filles, cartes buteurs, infos ;
- la démo admin (bouton « Admin » en haut, n'importe quel mot de passe) : valider un but déclenche la célébration « BUUUT ! ».

Ce qui est volontairement simple et doit être nettement amélioré : le stade (blocs), la foule (cubes),
l'éclairage, les matériaux. Le style, l'ordre des scènes et la structure des pages, eux, sont validés.

Version en ligne (privée, partagée par le porteur du projet si besoin) :
https://claude.ai/artifact/L6PucuCWEdxwd92U4Vc7rw
